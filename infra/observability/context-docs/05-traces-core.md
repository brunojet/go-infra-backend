# Prompt: Implementação do Core/Orquestração de Traces

Com base nos contratos definidos, implemente o core/orquestração do domínio de traces. Considere:
- Como centralizar o gerenciamento de spans e contexto?
- Como expor helpers para facilitar o uso dos contratos?
- Como garantir inicialização e shutdown corretos?

Exemplo de perguntas para guiar a implementação:
- Como propagar contexto de trace entre serviços?
- Como facilitar a instrumentação de middlewares e handlers?
